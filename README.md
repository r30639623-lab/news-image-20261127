A newspaper front page summing up Friday 27 November 2026's world news in
one image: 35 stories across 7 regions — a Kuwait drone attack killing two
Italians, China testing new Taiwan landing tactics, Zelenskyy warning of a
mass attack on the power grid, and the rest of the day's news, every story
dated 27 November 2026. The image is drawn with Pillow (`build27-v5.py`);
`main.py` copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To re-render the image from scratch:

```sh
python3 build27-v5.py
```
